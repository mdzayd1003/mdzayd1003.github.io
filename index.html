How I work

Four habits that show up in every project below. Each one is followed by the place it actually cost me something — a result I had to weaken, a claim I had to drop, a bug the habit caught.

Check against something I didn't write

A model that agrees with itself has told you nothing. I look for an independent reference — an empirical chart, a second implementation, a hand-labelled sample — and report the gap.

The MATLAB and Python ports of the acoustics model agree to 0.002 dB across all 3,024 band values. A test fails above 0.05.

Report the interval, not the number

Small samples make point estimates theatre. Proportions get Wilson intervals, differences get permutation tests, agreement gets a bootstrap — and the interval decides what I'm allowed to claim.

A 1.7-point accuracy gap between two vision models came back at p = 0.61. I reported it as no difference.

Never repair the evidence

When a model emits malformed output, retrying until it parses deletes the measurement. Parse failures are recorded, counted, and excluded — because how often a model holds its format is part of the result.

2 of 45 judge verdicts came back as prose. They stayed in the report as parse failures, not as retries.

Say which numbers aren't real yet

Placeholder results are fine; unlabelled placeholder results are not. Where a run is synthetic, the report says so, and a test asserts that it says so.

The listening-test ratings are simulated. It's in the file's provenance record, in the report, and in a test.

Multi-Agent Research Assistant with RAG

An orchestrator splits a question into subtasks and hands them to researcher, analyst, writer and critic agents over one JSON tool-calling contract. The retrieval side is written from scratch rather than imported — recursive splitting, a hashing embedder, exact cosine search — so every stage is inspectable, and FAISS only takes over once a corpus is large enough to earn it.

  • Whole pipeline runs with no model and no network; the offline path is the one the tests exercise.
  • Every LLM call, tool call and agent message traced to JSONL, fsynced per line.
  • Malformed replies end the agent's turn and are counted — never retried.

Principal-Agent Drift in LLM Negotiation

Does an agent stay inside the mandate its principal gave it when the other side pushes? 45 episodes across five pressure conditions, with mandate violations detected by rules that always attach the quote that triggered them. The counterparty is scripted, not modelled — otherwise a difference between conditions could come from the counterparty rather than the pressure.

  • Judge against rules: κ = 0.62, 95% CI [0.31, 0.88] by bootstrap.
  • Exact McNemar p = 0.031 — the judge is systematically more lenient, not just noisier.
  • Wilson intervals throughout: at n = 9 per condition, a Wald interval is degenerate.

Cross-Lingual Consistency in Model Behaviour

A matched English–Hindi prompt set asking whether a model gives the same answer, makes the same decision, and refuses in the same places in both languages. Every item carries a comprehension control, so “behaved differently” can be separated from “didn't understand the Hindi” — without it the headline result is unreadable.

  • Devanagari digits normalised before scoring, so ४२ and 42 are one answer, not a difference.
  • Refusal cues held per language and both sets always checked — models given Hindi sometimes refuse in English.
  • Hedges are excluded by name: “I can't be certain” is not a refusal.

Robustness under Image Corruption

The Hendrycks & Dietterich protocol end to end: 19 corruptions × 5 severities, per-corruption error, mCE and relative mCE. The corruptions are implemented here rather than downloaded, so the benchmark regenerates from CIFAR-10 offline instead of needing a 2.9 GB archive.

  • Severity ordering tested per corruption — including the three where pixel distance legitimately isn't monotone, each checked on the quantity that is.
  • CIFAR-10 has no canonical AlexNet baseline, so mCE normalises against a reference you train, and says so when you don't.
  • A baseline that's perfect on a corruption drops it from the mean and names it, rather than letting an infinity in.

CNN vs Vision Transformer

ResNet-18 against ViT-Tiny across a 16-run ablation grid — but the headline number is the least interesting output. The work is in the class-level analysis: where each model wins class by class, what it confuses, and how wrong it is when it's wrong.

Deep Learning Model Analysis

Less “train a model”, more “look inside one”. Calibration with ECE, MCE and Brier; layer-wise linear and k-NN probes; linear CKA between layers; effective dimensionality; a t-SNE that ships with the numbers it stands in for.

  • Temperature fitted on a held-out split — fitting it on the test set gives a number that can't be wrong, and so says nothing.
  • CKA between the last stage and its pooled output must be 1.00; it's a free correctness check on the taps, asserted every run.
  • MCE ignores near-empty bins, which otherwise report 1.0 about a single sample.

Sound Occlusion via Edge Diffraction

How much does a barrier actually block? Uniform Theory of Diffraction over a rigid wedge, a 126-configuration crossed parameter study in 24 third-octave bands, and two independent implementations that are tested against each other. The figure at the top of this page is one geometry from this study.

  • At the shadow boundary the field is 0.50 ± 0.03 of free field — exact by theory, nothing fitted to produce it.
  • Reciprocity holds to machine precision. It didn't at first: an angular separation taken modulo 2π isn't symmetric, and that broke everything above it.
  • MATLAB and Python agree to 0.002 dB; a test fails above 0.05.

What these numbers are

Every figure on this page comes from a run you can reproduce from the linked repository. Several come from synthetic or simulated data — the quick paths that let each project run on a laptop CPU with no downloads — and where that's true, the repository says so in the results directory, in the report, and in a test that asserts the report says so.

Concretely: the acoustics numbers are real output of the real model, but its listening-test ratings are generated rather than collected. The CIFAR results in each results/ folder are quick runs on synthetic data proving the pipeline, not statements about ResNet-18. Full-scale numbers go in after a GPU run, and not before.
